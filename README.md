# 🕵️ Marauder - Investigation Dashboard

> Plateforme d'investigation avancée avec interface ultra pro et intégration API BrixHub.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Node](https://img.shields.io/badge/node-18.x-green)

---

## ✨ Fonctionnalités

- 🔐 **Authentification sécurisée** - JWT + bcrypt
- 🎨 **Dashboard ultra pro** - Design noir, animations fluides
- 🔍 **Recherche avancée** - Multi-critères avec score de confiance
- 📞 **Lookup rapide** - Email, téléphone, IBAN
- 📊 **Historique** - Toutes vos recherches sauvegardées
- 👤 **Profil utilisateur** - Statistiques et informations
- 🚀 **Déployé sur Railway** - Base de données PostgreSQL intégrée

---

## 🏗️ Stack Technique

| Catégorie | Technologie |
|-----------|-------------|
| Backend | Node.js + Express |
| Base de données | PostgreSQL |
| Authentification | JWT + bcrypt |
| API externe | BrixHub v1 |
| Frontend | HTML/CSS/JS vanilla |
| Hébergement | Railway |
