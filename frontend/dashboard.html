Documentation

Guide complet d'utilisation de l'API

Introduction

L'API Marauder vous permet d'accéder aux données d'investigation OSINT de manière programmatique. Utilisez-la pour automatiser vos recherches, intégrer Marauder dans vos outils existants, ou créer vos propres applications.

URL de base : https://marauder.host/api/v1 Format : JSON Authentification : Clé API

Authentification

Toutes les requêtes doivent inclure votre clé API dans le header Authorization :

Header 
Authorization: Bearer marauder_xxxxxxxxxxxxxxxxxxxxxxxx

Recherche

Recherchez des personnes avec plus de 20 critères.

POST /api/v1/search

Paramètres (JSON) :

Body 
{
    "nom_famille": "Dupont",
    "prenom": "Jean",
    "email": "jean@example.com",
    "telephone": "0612345678",
    "ville": "Paris",
    "flexible": true,
    "per_page": 100
}

Lookup

Recherche rapide par email, téléphone ou IBAN.

GET /api/v1/lookup/:type/:value
Exemple 
GET /api/v1/lookup/email/jean@example.com
GET /api/v1/lookup/phone/0612345678
GET /api/v1/lookup/iban/FR76...
