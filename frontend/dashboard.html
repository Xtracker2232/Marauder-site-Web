Documentation

Guide complet de l'API v1

Introduction

L'API Marauder permet d'accéder aux données d'investigation OSINT de manière programmatique. Toutes les requêtes doivent être authentifiées avec votre clé API.

URL de base : https://marauder.host/api/v1 Format : JSON Auth : Bearer Token

Authentification

Ajoutez votre clé API dans le header Authorization :

Header
Authorization: Bearer marauder_xxxxxxxxxxxxx

⚠️ Ne partagez jamais votre clé API.

Prompt IA prêt à copier

Copiez-collez ce prompt dans ChatGPT / Claude / une autre IA pour qu'elle utilise l'API Marauder :

Prompt pour IA
Tu es un assistant qui utilise l'API Marauder (OSINT).

URL de base : https://marauder.host/api/v1
Clé API : marauder_VOTRE_CLE_ICI

Endpoints :
- POST /search → recherche multi-critères
- GET /me → infos compte + quota
- GET /usage → stats détaillées

Pour appeler l'API :
curl https://marauder.host/api/v1/search \
  -H "Authorization: Bearer marauder_VOTRE_CLE_ICI" \
  -H "Content-Type: application/json" \
  -d '{"nom_famille": "Dupont", "prenom": "Jean"}'

Fais la recherche et affiche les résultats.
