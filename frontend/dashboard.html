Documentation API v1

Guide complet — tous les endpoints, exemples et limites

Informations générales

L'API Marauder vous permet d'accéder aux données d'investigation OSINT de manière programmatique. Automatisez vos recherches, intégrez Marauder dans vos outils existants, ou créez vos propres applications.

URL de base : https://marauder.host/api/v1 Format : JSON Authentification : Clé API (Bearer) Version : v1

Authentification

Toutes les requêtes doivent inclure votre clé API dans le header Authorization :

Header
Authorization: Bearer marauder_xxxxxxxxxxxxxxxxxxxxxxxx

⚠️ Ne partagez jamais votre clé API. Elle donne accès complet à votre compte et à votre quota.

Limites par plan

Mon profil — GET /me

Récupère les informations de votre compte et l'usage de votre quota ce mois-ci.

GET/api/v1/me
Exemple cURL
curl https://marauder.host/api/v1/me \
  -H "Authorization: Bearer marauder_xxx"

Réponse :

JSON
{
  "success": true,
  "plan": "starter",
  "resultsPerSearch": 50,
  "usage": {
    "used": 4,
    "limit": 1000,
    "remaining": 996
  }
}

Statistiques — GET /usage

Récupère les statistiques détaillées de votre consommation d'API (jour, mois, et répartition par endpoint).

GET/api/v1/usage
Exemple cURL
curl https://marauder.host/api/v1/usage \
  -H "Authorization: Bearer marauder_xxx"

Réponse :

JSON
{
  "success": true,
  "plan": "starter",
  "resultsPerSearch": 50,
  "usage": {
    "today": 2,
    "month": 4,
    "limit": 1000,

    "by_endpoint": [
      { "endpoint": "/api/v1/search", "total": "3" },
      { "endpoint": "/api/v1/me", "total": "1" }
    ]
  }
}
