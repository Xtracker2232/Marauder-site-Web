Guide complet — tous les endpoints, exemples et limites

Informations générales

L'API Marauder vous permet d'accéder aux données d'investigation OSINT de manière programmatique. Automatisez vos recherches, intégrez Marauder dans vos outils existants, ou créez vos propres applications.

URL de base : https://marauder.host/api/v1 Format : JSON Authentification : Clé API (Bearer) Version : v1

Authentification

Toutes les requêtes doivent inclure votre clé API dans le header Authorization :

Header
Authorization: Bearer marauder_xxxxxxxxxxxxxxxxxxxxxxxx

⚠️ Ne partagez jamais votre clé API. Elle donne accès complet à votre compte et à votre quota.

Mon profil — GET /me

Récupère les informations de votre compte et l'usage de votre quota ce mois-ci.

GET/api/v1/me
Exemple cURL
curl https://marauder.host/api/v1/me \
  -H "Authorization: Bearer marauder_xxx"

Réponse :

JSON
{
  "success": true,
  "plan": "free",
  "resultsPerSearch": 10,
  "usage": {
    "used": 4,
    "limit": 10,
    "remaining": 6
  }
}

Statistiques d'utilisation — GET /usage

Récupère les statistiques détaillées de votre consommation d'API (requêtes du jour, du mois, et répartition par endpoint).

GET/api/v1/usage

curl https://marauder.host/api/v1/usage \

Recherche familiale par pivot — POST /search

Trouve toutes les personnes reliées à un numéro de téléphone ou une adresse partagée. Utilise POST /search avec flexible: true et un per_page élevé pour récupérer le cluster familial complet.

POST/api/v1/search

Exemple — Pivot par téléphone :

Body JSON
{
  "telephone": "0612345678",
  "flexible": true,
  "per_page": 100
}

Exemple — Pivot par adresse :

Body JSON
{
  "adresse": "10 rue de la Paix, 75001 Paris",
  "flexible": true,
  "per_page": 100
}

Réponse — Cluster familial :

JSON
{
  "success": true,
  "data": {
    "results": [
      {
        "nom_famille": "Dupont",
        "prenom": "Jean",
        "telephone": "0612345678",
        "adresse": "10 rue de la Paix, 75001 Paris",
        "_confidence": 95,
        "_relation": "Titulaire principal",
        "_linkTypes": ["phone", "address"]
      },
      {
        "nom_famille": "Dupont",
        "prenom": "Marie",
        "telephone": "0612345678",
        "adresse": "10 rue de la Paix, 75001 Paris",
        "_confidence": 92,
        "_relation": "Conjoint(e)",
        "_linkTypes": ["phone", "address"]
      },
      {
        "nom_famille": "Dupont",
        "prenom": "Lucas",
        "adresse": "10 rue de la Paix, 75001 Paris",
        "_confidence": 85,
        "_relation": "Enfant",
        "_linkTypes": ["address"]
      }
    ]
  },
  "meta": {
    "total": 4,
    "returned": 4,
    "maintenance": false
  }
}

Champs de cluster :

_relationRelation déduite (Titulaire, Conjoint, Enfant, Contact proche...)
_linkTypesTypes de liens détectés : phone, address ou les deux

Lookup rapide — GET /lookup/:type/:value ❌

⚠️ Cette route est actuellement INDISPONIBLE car notre fournisseur de données ne propose pas l'endpoint lookup.

GET/api/v1/lookup/:type/:value

Types disponibles : email, phone, iban

Réponse quand appelée :

JSON
{
  "error": "upstream_unavailable",
  "message": "Le fournisseur de données est temporairement indisponible."
}
⚠️ Utilisez /search à la place.
Exemple : {"email": "jean@example.com"} via POST /search

Codes d'erreur

200Succès
400Requête invalide (body mal formé)
401Clé API manquante ou invalide
403Accès refusé (banni, quota dépassé)
404Route ou ressource introuvable
429Quota mensuel dépassé
500Erreur serveur
503Fournisseur de données indisponible

Exemples de code

cURL
curl -X POST https://marauder.host/api/v1/search \
  -H "Authorization: Bearer marauder_xxx" \
  -H "Content-Type: application/json" \
  -d '{"nom_famille": "Dupont", "prenom": "Jean"}'
