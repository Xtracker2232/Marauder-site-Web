Guide complet de l'API v1

Introduction

L'API Marauder vous permet d'accéder aux données d'investigation OSINT de manière programmatique.

URL : https://marauder.host/api/v1 Format : JSON Auth : Clé API

Authentification

Toutes les requêtes incluent votre clé dans le header :

Header
Authorization: Bearer marauder_xxxxxxxxxxxxxxxxxxxxxxxx

Recherche multi-critères

Recherchez des personnes avec plus de 20 critères.

POST/api/v1/search
Exemple
curl -X POST https://marauder.host/api/v1/search \
  -H "Authorization: Bearer marauder_xxx" \
  -H "Content-Type: application/json" \
  -d '{"nom_famille": "Dupont", "prenom": "Jean"}'
