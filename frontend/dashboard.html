Documentation

Guide complet d'utilisation de l'API v1

Introduction

L'API Marauder vous permet d'accéder aux données d'investigation OSINT de manière programmatique. Automatisez vos recherches, intégrez Marauder dans vos outils existants, ou créez vos propres applications.

URL de base : https://marauder.host/api/v1 Format : JSON Authentification : Clé API

Authentification

Toutes les requêtes doivent inclure votre clé API dans le header Authorization :

Header
Authorization: Bearer marauder_xxxxxxxxxxxxxxxxxxxxxxxx

⚠️ Ne partagez jamais votre clé API. Elle donne accès complet à votre compte.

Mon profil

Récupère les informations de votre compte et l'usage de votre quota ce mois-ci.

GET/api/v1/me
Exemple
curl https://marauder.host/api/v1/me \
  -H "Authorization: Bearer marauder_xxx"

Réponse :

JSON
{
  "success": true,
  "plan": "free",
  "resultsPerSearch": 10,
  "usage": {
    "used": 4,
    "limit": 10,
    "remaining": 6
  }
}

Statistiques d'utilisation

Récupère les statistiques détaillées de votre consommation d'API (requêtes du jour, du mois, et répartition par endpoint).

GET/api/v1/usage
Exemple
curl https://marauder.host/api/v1/usage \
  -H "Authorization: Bearer marauder_xxx"

Réponse :

JSON
{
  "success": true,
  "plan": "free",

      { "endpoint": "/api/v1/search", "total": "3" },

Lookup rapide

GET/api/v1/lookup/:type/:value

Types disponibles : email, phone, iban

Réponse quand appelée :

JSON
{
  "error": "upstream_unavailable",
  "message": "Le fournisseur de données est temporairement indisponible."
}
⚠️ Utilisez /search à la place.
